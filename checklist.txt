  - Result: /etc/ssh.conf is created and updated by the shell
- Numbered config flows added

    - net config
    - wifi config
    - disk config
    - drivers config
    - ssh config

Known not working
- e1000 packet driver binding
  - Guest detects Intel 8086:100e at 0:3.0
  - net status still reports:
    - Network: network device found, no packet driver for it yet
    - Packet driver: not loaded
- ping over e1000
  - Blocked because the e1000 packet driver is still not active
- Real SSH transport
  - The ssh command surface exists, but TCP/IP and SSH session transport are not implemented yet
- Real WiFi data path
  - Detection and driver selection exist, but there is still no working wireless packet/data path
- Real persistent storage install
  - Installer writes modeled install state and manifests, but the repo still lacks real ATA/AHCI/NVMe block drivers
- Remote web fetch in browser
  - Browser mode exists, but remote HTTP/HTTPS pages are not implemented
